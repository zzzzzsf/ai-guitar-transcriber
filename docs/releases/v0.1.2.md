# AI 智能扒谱 v0.1.2

本版整合音频导入、谱面时值、多声部、AI 改谱和工程底层的修复。

- 调整音频移除、换歌、档位切换及改谱撤销的状态管理。
- 修复同时起音的和弦、独立声部、跨小节延音、长曲导出和推弦单位处理。
- 加强 AI 改谱的速度、调号、调弦、Capo、音符和奏法校验，拆轨增加联合检查。
- 调整原曲对照的播放速度、波形媒体和循环区间处理。
- 加强工程保存、目录操作、模型下载校验及原生分轨任务隔离。
- 发布流程验证版本与触发标签一致，在资产准备和检查完成后公开版本。

## 下载

- `AI-Guitar-Transcriber_0.1.2_x64-setup.exe`：Windows x64 安装器。
- `portable-windows-x64.zip`：便携版，解压运行；系统需安装 WebView2。
- `.exe.sig` 与 `latest.json`：应用更新所需签名和元数据。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

## 已知限制

这是早期版本，尚未完成完整的桌面听音、真实录音准确率和安装升级验收。均衡/高配档依赖的真实分轨程序与模型尚未随本次发布打包，无法运行时会降级至轻量档。

工程保存、导出和人工编辑的完整界面流程仍待完善；三连音、自由节奏及小节中途变速等场景仍有待验证或完善。首次使用可能需要下载模型；连接第三方 AI 后，改谱等操作会向所选服务发送谱面和指令。

依赖许可声明随安装包和便携版提供。更多修复依据见仓库 `docs/修复进度-2026-11-15.md` 与 `docs/修复记录-F01-F23-2026-11-15.md`。
