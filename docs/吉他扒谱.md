# AI 智能扒谱软件项目方案与技术架构文档 (v4.0 AI 编程专享 & 高颜值跨端版)

## 1. 项目概述与核心定位

### 1.1 项目目标与演进策略
本项目旨在利用 AI 辅助编程构建一款**高颜值、免费开源、本地离线优先的智能音乐扒谱软件**。
* **乐器拓展路线（Guitar-First）**：
  * **首期聚焦吉他**：专精原声木吉他（指弹/弹唱）与电吉他（Solo/Riff），自动生成符合人类手指生理结构的**吉他六线谱（Tab）与五线谱**。
  * **远期拓展多乐器**：通过插件化的“乐器物理规则引擎（`InstrumentProfile`）”，平滑扩展至**贝斯（四线谱）、人声（简谱/五线谱）、钢琴（双手大谱表）及架子鼓（鼓谱）**。
* **平台演进路线（PC-First to Mobile）**：
  * **首期落地电脑桌面端（Windows / macOS）**：采用现代 Web 跨端桌面架构，打造专业音乐宿主（DAW）级暗黑磨砂质感 UI。
  * **二期平滑移植移动端（Android / iOS）**：100% 复用前端界面、吉他指法算法与轻量转谱引擎，一键打包生成移动端 App。

### 1.2 核心产品原则
1. **用户自选“高低配”档位（零硬件探测复杂度）**：放弃复杂的底层硬件自动探测，在界面上提供清晰的**【轻量极速档 / 均衡标准档 / 高配精析档】**切换开关，让用户根据自身设备性能与音频类型自由选择。
2. **零成本与本地离线优先**：核心音源分离与音符转写全部采用免费开源模型在本地运行，用户零订阅费，开发者零云端服务器成本。
3. **可选大模型 API 赋能（BYOK 模式）**：支持用户填入自有通用大模型 API Key（DeepSeek / Gemini / OpenAI / Kimi 等），基于 `alphaTex` 纯文本六线谱格式实现智能和弦标注、把位简化与错音清洗。
4. **全链路 MIT 开源合规**：主程序采用 **MIT 协议**，所有第三方依赖均严格筛选宽松开源许可证（MIT / Apache 2.0 / BSD / MPL 2.0 / LGPL）。

## 3. 用户可选的“三级性能档位”设计

用户在导入音频时，可在界面上直观选择以下三种运行档位（代码层面仅需简单的分支路由）：

| 档位名称 | 适用设备与场景 | 底层执行策略 | 内存占用与预计耗时 (3分钟歌曲) |
| :--- | :--- | :--- | :--- |
| **⚡ 轻量极速档**<br>*(Low-Spec / Solo Mode)* | • **老旧低配电脑 / 千元手机**<br>• 纯吉他独奏、指弹录音、干净弹唱 | **跳过重型分轨模型** -> 仅通过 Web Audio API 做基础带通滤波（滤除极低频与超高频噪点） -> 直接运行前端 **Basic Pitch (17MB)** -> 生成吉他六线谱。 | • 峰值内存：**< 300 MB**<br>• 耗时：**5 ~ 15 秒**<br>• 100% 设备零闪退 |
| **⚖️ 均衡标准档**<br>*(Balanced Mode)* | • **主流核显轻薄本 / 主流手机**<br>• 需要从混音歌曲中提取吉他 | 调用 **INT8 量化版轻量分轨模型** -> 强制开启 **3 秒小窗口切片流式推理**（严格限制内存峰值） -> 释放分轨内存 -> 运行 Basic Pitch 转谱。 | • 峰值内存：**450 ~ 700 MB**<br>• 耗时：**1 ~ 2.5 分钟**<br>• 兼顾混音分轨与防崩保护 |
| **🚀 高配精析档**<br>*(High-Spec Pro Mode)* | • **带独显的台式机 / 游戏本 / M系 Mac**<br>• 追求复杂乐队混音下的最高准确率 | 调用本地 **`htdemucs_6s` 完整六轨高精度模型 (FP16/FP32)** -> 开启 GPU 硬件加速（DirectML / CUDA / CoreML）与 10 秒高重叠窗口 -> 剥离出纯净吉他轨后再转六线谱。 | • 峰值内存：**1.5 ~ 2.5 GB**<br>• 独显耗时：**10 ~ 25 秒**<br>• 分轨纯净度与还原度最高 |

*(注：为保持基础软件安装包极度小巧，软件本体默认内置 17MB 的【轻量极速档】引擎；当用户在电脑上首次切换到【均衡档 / 高配档】时，软件内提供一键自动从国内镜像/HuggingFace 下载对应分轨扩展包的功能。)*

## 4. 核心技术流水线与吉他专精算法 (`GuitarProfile`)

### 4.1 吉他专精五步后处理流水线（全 TypeScript 实现）

`Basic Pitch` 输出的原始音符仅包含时间、音高（MIDI Pitch）与弯音曲线，必须经过以下纯 TypeScript 编写的 **`GuitarProfile` 规则引擎**转化为可弹奏的六线谱：

1. **吉他物理音域与复音硬约束过滤**
   * **音域截断**：标准 6 弦 24 品吉他音域为 `E2 (MIDI 40)` 至 `E6 (MIDI 88)`（Drop D 兼容至 `D2 / MIDI 38`）。超出 `[38, 88]` 范围的音符直接作为底鼓或镲片串音剔除。
   * **同帧复音上限**：同一时间点最多保留能量（Velocity）最高的 **6 个音符**（对应 6 根琴弦），并剔除持续时间 `小于 35ms` 的孤立泛音碎音。
2. **扫弦时间窗聚拢（Strum Clustering）与推弦合并（Bend Merger）**
   * **扫弦防碎处理**：吉他扫弦拨片划过 6 根弦存在 `20ms ~ 60ms` 物理延迟。算法检测 `50ms` 窗口内按音高单调递增（下扫 `↓`）或递减（上扫 `↑`）依次触发的音符簇，将其起始时间强制对齐到同一节拍网格，防止六线谱把扫弦错误渲染成碎琶音。
   * **推弦/滑音还原**：结合 Basic Pitch 输出的 `pitchBend` 数组，将连续滑动的半音碎片合并为单一音符，并挂载 `alphaTex` 的推弦（`{b(0 4)}`）或滑音（`{s}`）标签。
3. **调弦与变调夹自动推导器（Auto-Capo Detector）**
   * 自动遍历标准调弦、`Drop D` 及 `Capo 0 ~ 7 品`，评估各配置下的**空弦音（0品）命中率**与**手指平均跨度**，自动推荐最省力的变调夹位置（同时支持用户在 UI 顶部下拉框随时切换 Capo 品格，前端毫秒级实时重算指法）。
4. **基于动态规划（Viterbi 算法）的六线谱弦品寻路**
   * 吉他同一音高可在多根弦弹出（如 `E4` 可在 1弦0品、2弦5品、3弦9品、4弦14品弹出）。利用 **Viterbi 算法**求全局最优指法路径，代价函数（Cost Function）包含：
     * **同弦互斥硬约束**：同一时刻的两个音绝不能分配在同一根弦上。
     * **单手跨度惩罚**：同一和弦内（不含空弦 `0` 品），最高品与最低品之差若 `大于 4 品`，施加指数级惩罚。
     * **把位移动惩罚**：相邻音符/和弦之间的手掌中心把位（Fret Hand Position）跳跃越大，惩罚越高。
5. **生成 `alphaTex` 标准文本并交由 `alphaTab` 渲染**
   * 将计算好“第几弦、第几品、几分音符”的序列直接格式化为 `alphaTex` 纯文本字符串（如 `0.6.4 2.5.8 3.5.8 | 3.2.2{b(0 4)}`），直接传入 `alphaTab` 渲染出支持视奏跟播的交互式六线谱与五线谱。

### 4.2 通用大模型 API 乐理增强层（BYOK 模式）

由于内部采用了极度紧凑的 `alphaTex` 纯文本格式（一首 4 分钟吉他谱仅约 1,500 ~ 3,000 Tokens），用户填入自己的 DeepSeek / Gemini / OpenAI API Key 后，前端可直接通过标准 `fetch` 请求实现三大功能：

1. **吉他和弦图与级数自动标注**：大模型读取每小节的 `alphaTex` 弦品音符，自动在每小节上方插入标准吉他和弦标记（如 `Em7`、`Cadd9`、`D/F#`）及调内级数。
2. **自然语言把位重构与新手降维**：用户框选几小节难弹的曲谱，点击“AI 改谱”（如输入：*“把这段高把位 Solo 改写到前 5 品内”* 或 *“把这段复杂指弹简化为新手好按的分解和弦”*），大模型直接返回修改后的 `alphaTex` 代码并实时刷新谱面。
3. **主音/节奏双吉他智能拆轨**：当单轨吉他同时混杂了 Solo 与伴奏扫弦时，大模型结合声部走向将其拆分为 `Lead Guitar` 与 `Rhythm Guitar` 双轨谱表。

### 4.3 多乐器插件化扩展接口 (`IInstrumentProfile`)

后续扩展其他乐器时，UI 与底层转谱引擎无需改动，仅需在 `src/profiles/` 目录下让 AI 新增一个 TypeScript 规则类：

| 插件类名称 | 乐器配置 | 核心后处理逻辑 | 输出谱面类型 |
| :--- | :--- | :--- | :--- |
| **`GuitarProfile.ts` (首期)** | 6 弦标准/特殊调弦 | Capo 推导、扫弦聚拢、6 弦 Viterbi 寻路、推弦合并 | 吉他六线谱 (Tab) + 五线谱 |
| **`BassProfile.ts` (二期)** | 4 弦 / 5 弦贝斯 | 单音/双音约束、低频泛音清洗、4 弦把位寻路 | 贝斯四线谱 (Tab) |
| **`VocalProfile.ts` (二期)** | 单声部人声旋律 | 严格单音约束（Monophonic）、颤音平滑、调号识别 | 简谱 / 单行五线谱 |
| **`PianoProfile.ts` (三期)** | 88 键双谱表 | 左右手音域动态切分（Split Point）、延音踏板对齐 | 钢琴高低音大谱表 |
| **`DrumProfile.ts` (三期)** | 架子鼓打击乐 | 瞬态峰值映射至底鼓/军鼓/踩镲标准 MIDI 键位 | 标准架子鼓谱 |

## 7. 分阶段 AI 辅助开发路线图（每次只让 AI 写一个独立模块）

* **Step 1（1天跑通高颜值界面与六线谱渲染）**：让 AI 初始化 `React + TypeScript + Tailwind` 项目，集成 `alphaTab`，先用一段写死的 `alphaTex` 测试字符串渲染出带播放光标的暗黑风吉他六线谱界面。
* **Step 2（实现吉他弦品寻路核心算法 `GuitarProfile.ts`）**：让 AI 编写纯 TypeScript 的 `GuitarProfile.ts`（输入 MIDI 音符数组，经过 Viterbi 动态规划算法输出 `alphaTex` 六线谱字符串），这是整个软件最核心的护城河。
* **Step 3（接入 `Basic Pitch` 跑通“轻量极速档”闭环）**：接入 `@spotify/basic-pitch`，实现拖入一段吉他独奏 MP3/WAV -> 10 秒内自动转出 MIDI 音符 -> 经 `GuitarProfile` 转为六线谱并显示在界面上。
* **Step 4（接入“高配/标准档”分轨子进程与大模型 BYOK 面板）**：加上高低配档位切换开关，对接本地 Demucs 分轨命令行工具，并接入大模型 API 实现自动标和弦与智能改谱。
